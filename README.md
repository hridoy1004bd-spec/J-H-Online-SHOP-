# J H Online SHOP — React Prototype

এই প্রজেক্টটা একটা Vite + React (TypeScript) অ্যাপ। ডিজাইন: নেভি + গোল্ড থিম, বাংলা/ইংরেজি ভাষা টগল, কাস্টমার অ্যাপ (হোম, ক্যাটাগরি, প্রোডাক্ট ডিটেইল, কার্ট, চেকআউট w/ demo OTP, অর্ডার ট্র্যাকিং) এবং সেলার অ্যাডমিন প্যানেল (ড্যাশবোর্ড, পণ্য যোগ/মুছা, অর্ডার ম্যানেজমেন্ট)। সব ডেটা in-memory ডেমো — রিফ্রেশ করলে মুছে যাবে।

## আপনার GitHub রিপোতে বসানোর ধাপ

আপনার বর্তমান রিপোর `src` ফোল্ডার এলোমেলো অবস্থায় আছে (অনেক আলাদা ফাইল, ব্যর্থ ডিপ্লয়মেন্ট)। সবচেয়ে নিরাপদ উপায়:

1. GitHub রিপোতে গিয়ে পুরনো এই ফাইল/ফোল্ডারগুলো ডিলিট করুন: `src/` (পুরো ফোল্ডার), root-এর পুরনো `index.html`, পুরনো `package.json`
2. "Add file → Upload files" দিয়ে এই ZIP-এর সব ফাইল আপলোড করুন — ফোল্ডার স্ট্রাকচার (`src/App.tsx`, `src/main.tsx`) ঠিক রেখে
3. Commit করুন (main ব্রাঞ্চে)
4. Vercel → আপনার প্রজেক্ট → Settings → Git → Production Branch যেন `main` হয় তা নিশ্চিত করুন
5. Vercel অটো নতুন ডিপ্লয় শুরু করবে (Framework: Vite, Build Command: `npm run build`, Output: `dist` — এগুলো Vercel অটো ডিটেক্ট করবে)

## লোকালি রান করতে চাইলে

```bash
npm install
npm run dev
```

## বিল্ড করতে চাইলে

```bash
npm run build
```

`dist/` ফোল্ডারে স্ট্যাটিক ফাইল তৈরি হবে।

## গুরুত্বপূর্ণ নোট

- এটা একটা **ফ্রন্টএন্ড-অনলি প্রোটোটাইপ** — কোনো real ব্যাকএন্ড/ডেটাবেস নেই। অর্ডার, পণ্য, কাস্টমার — সব browser memory-তে থাকে, পেজ রিফ্রেশ করলে হারিয়ে যায়।
- OTP verification simulated — আসল SMS পাঠায় না, স্ক্রিনে কোড দেখিয়ে দেয়।
- Payment শুধু "Cash on Delivery" — bKash/Nagad/Card যোগ করতে হলে পেমেন্ট গেটওয়ে API ও ব্যাকএন্ড লাগবে।
- Real ডেটা persist করতে (Google Sheet/Database), এবং real SMS OTP, real payment — এই ফিচারগুলো যোগ করতে চাইলে জানাবেন, পরবর্তী ধাপে সেটা নিয়ে কাজ করা যাবে।
